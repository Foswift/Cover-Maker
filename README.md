# 封面制作器

一张画布，同时做好抖音、小红书、快手、哔哩哔哩、视频号等平台的封面。Mac 桌面版（Electron）。

- 各平台封面比例的引导框，一次排好、每个平台各导出一张
- 文字描边 / 阴影 / 斜切 / 字间距 / 文字路径，内置字体库
- 贴纸、形状、图层、提取主体、吸管取色、橡皮擦、标尺参考线
- 「我的模板」：存下排版，下次一键套用；撤销重做不限步数
- 可让 AI 助手通过 MCP（本机 127.0.0.1:37651）一句话做封面
- 完全离线运行，图片不上传

下载安装包：<https://foswift.com/download>

## 从源码运行

需要 Node.js 22。

```bash
npm install
npm start        # 运行
npm run dev      # 开发模式
npm run check    # 语法检查
npm run build:mac  # 打 Mac 包（arm64 + x64），需要 Python
```
