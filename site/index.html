    Mac 怎么安装

    1. 双击下载的 zip 解压，得到「封面制作器.app」和「首次打开.command」。
    2. 双击「封面制作器.app」打开。
    3. 如果提示「无法检查其是否包含恶意软件」：右键点它 → 选「打开」→ 再点「打开」，只需一次。
    4. 如果还是打不开（提示「已损坏」）：双击「首次打开.command」，跑完就能正常打开了。

    升级新版本：下载后直接替换旧的「封面制作器.app」，作品、模板、字体和贴纸都会保留。

    能做什么

    • 各平台封面比例的引导框，一次排好、每个平台各导出一张
    • 文字描边 / 阴影 / 斜切 / 字间距 / 文字路径，内置字体库
    • 贴纸、图层、提取主体、吸管取色、橡皮擦
    • 「我的模板」：存下排版，下次一键套用；撤销重做不限步数
    • 完全离线运行，图片不上传
